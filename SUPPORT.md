# Support

Orkestra is free and open source under the [MIT License](LICENSE). It is a local tool: no hosted service, no telemetry.

## Get help

| Need | Where |
| --- | --- |
| Bug or feature | [GitHub Issues](https://github.com/soft-ai-solutions/orkestra/issues) (use the forms; blank issues are off) |
| Install or PATH problems | Run `orkestra doctor`, then [FAQ](README.md#faq-and-troubleshooting) ([Türkçe](README.tr.md#sss-ve-sorun-giderme)) |
| Security vulnerability | [Private advisory](https://github.com/soft-ai-solutions/orkestra/security/advisories/new) · [SECURITY.md](SECURITY.md) |
| Contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |
