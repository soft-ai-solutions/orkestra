# Buy Me a Coffee membership assets

Static cover and badge images for the Orkestra Patron (and other) membership levels on
[buymeacoffee.com/firatkocabay/membership](https://buymeacoffee.com/firatkocabay/membership).

| File | Use |
| --- | --- |
| `cover-1000x600.jpg` | Preferred cover upload (5:3, sharp) |
| `cover-250x150.jpg` | Exact size the studio UI recommends |
| `cover-16x9-source.jpg` | Full-bleed source if you re-crop |
| `badge-1200x1200.jpg` | Square card / badge |
| `badge-1024x1024.jpg` | Smaller square export |

These files are not loaded by the CLI or hooks. Funding links for readers: [SUPPORT.md](../../SUPPORT.md).
